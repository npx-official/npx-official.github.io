RESEARCH DESK

Research Queue — what deserves attention

HIGH VALUE

Authorization as a graph

Convert relationships between users → roles → objects → functions → tenants to a graph. Search for a missing edge instead of searching for a single payload.

MODERN

Parser / protocol differentials

Compare how a proxy, CDN, WAF, application server and backend interpret the same message. The goal is to understand the difference in interpretation in the laboratory.

API

Inventory drift

Compare OpenAPI/docs/mobile clients/JS/routes and legacy versions. An out-of-date API inventory may be hiding an unintended surface.

AI

Agent trust boundaries

Draw model → prompt → retrieval → tools → external services → secrets → user. Rate prompt injection, excessive agency, data leakage and supply-chain trust within lab.

Patch or mitigate, reduce exposure, rotate potentially exposed credentials/tokens and validate that the vulnerable path is no longer reachable.

Repeat version and exposure checks, confirm monitoring coverage and document evidence. Keep the assessment reproducible without weaponized payloads.
